# Writing a tabletop role-playing game content with Homebrewery

This project is a piece of original lore describing a wuxia-inspired guild of wandering warriors created for a _Dungeons & Dragons_ setting. While primarily a creative writing exercise, it is also designed to closely follow established D&D publishing conventions in terms of structure, layout, and visual presentation.

The document was formatted using Homebrewery, a web-based tool that enables creators to produce D&D content using a Markdown-like syntax.

## What this project demonstrates

- Ability to write clear, engaging narrative and explanatory content within a rigid stylistic framework
- Attention to formatting, hierarchy, and visual consistency 
- Ability to make custom content look indistinguishable from professionally published material

## Assumptions

- The reader has basic familiarity with _Dungeons & Dragons_ or tabletop role-playing games.
- The material is intended for experimental play, not competitive balance.

## Scope

This project includes narrative lore, character concepts, stat blocks, and custom mechanical elements. Playtesting, balance considerations, and campaign integration are intentionally out of scope.
