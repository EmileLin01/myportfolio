# About this portfolio...

Hi, I'm Emile. 

I'm a technical writer who creates clear, structured documentation for complex topics. Outside of my day-to-day work, I upskill through independent projects that let me explore different documentation formats, authoring tools, and problem spaces.

This portfolio includes non-proprietary projects created outside of professional employment. Because of confidentiality and NDA restrictions, I don’t publish internal or client documentation. Most of these projects aim to showcase how I approach documentation and writing across formats such as online help systems, long-form PDFs, structured markup, and interactive prototypes.

Projects are grouped by documentation type. Each one includes context around scope, assumptions, and design decisions.
