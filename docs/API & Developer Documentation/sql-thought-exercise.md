# Retrieving data using SQL

This project uses SQL to analyze longevity data for various zoo animals. The queries are intermediate in complexity and are intended to demonstrate SQL familiarity in support of analysis and documentation-related work.

The results are presented as an HTML document generated with Asciidoctor, with light CSS customization to improve readability and structure.

## What this project demonstrates

- Ability to write intermediate SQL queries
- Translating SQL queries output into clear, structured explanations
- Presenting technical analysis in a polished, reader-friendly format
- Comfort working with structured data 

## Assumptions

- The dataset is assumed to be clean for the purpose of analysis.
- The audience is technical and familiar with basic database concepts.
- The focus is on query logic and result interpretation rather than database administration.

## Scope

Database design, indexing strategies, and optimization are intentionally out of scope.
