# Writing a webhelp on the mutant apocalypse

This project is a short WebHelp guide on surviving a hypothetical mutant apocalypse, created using Oxygen XML and DITA. The content is authored as individual DITA topics and organized through a DITA map, with light CSS customization applied to the output. The project aims to demonstrate structured, topic-based authoring in DITA and familiarity with the Oxygen authoring environment.

## What this project demonstrates

- Structuring content into discrete, reusable DITA topics  
- Organizing topics and relationships through a DITA map  
- Applying CSS to customize the layout and presentation of WebHelp output  

## Assumptions

- The content covers a fictional mutant apocalypse scenario; details are invented for demonstration purposes.
- The audience is a survivor seeking explanatory information, not performing tasks.
- The WebHelp system is viewed in a modern browser; no device constraints are assumed.
- The project focuses on clarity and structure rather than usability testing.

## Scope

The project includes explanatory topics that outline the scenario and survival concepts. Only a subset of potential topics is included; advanced scenarios are intentionally excluded.
