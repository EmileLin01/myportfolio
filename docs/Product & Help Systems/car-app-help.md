# Generating online documentation with MkDocs

This project is an online help system for a fictional car recognition app, built using MkDocs. The content is written in Markdown and organized through a custom `mkdocs.yml` configuration to show how I think about structure, navigation, and topic organization. I also added light CSS customization to improve readability and overall presentation.

## What this project demonstrates

- Designing navigation and topic hierarchy in MkDocs
- Writing task-oriented help content for a non-technical audience
- Applying light visual customization 

## Assumptions

- The app is a consumer-facing mobile application with a relatively simple feature set.
- The primary audience is a first-time or casual user with no prior familiarity with the app.
- Product behavior and feature details are fabricated for the purpose of documentation, as the app is fictional.
- The help content prioritizes clarity over exhaustive feature coverage.

## Scope

This help system covers onboarding and core app functionality. It is not intended to be a production-ready help center.

Troubleshooting, edge cases, and accessibility considerations are intentionally out of scope.
