# Writing a webhelp for Nectari

This project is a conceptual online help system for Nectari Software Inc.'s "Formula Wizard" feature, created as part of an interview assessment using ClickHelp (trial version). The project involved organizing content, writing explanatory topics, and demonstrating how a help system could structure and present the feature to end users. A French version of the help system was also created, demonstrating consideration for multilingual support. 

The original hosted output is no longer available; this portfolio shows a write-up of the mock-up to highlight the approach, structure, and writing style. An offer was extended, but I chose not to accept it.

## What this project demonstrates

- Designing an online help system conceptually, including content hierarchy, visual support, and navigation  
- Writing explanatory topics that clarify feature functionality for end users  
- Understanding and writing about advanced accounting concepts under time constraint
- Considering localization and multilingual support (English/French toggle)

## Assumptions

- The intended audience is an accountant new to the "Formula Wizard" feature 
- The project is a conceptual mock-up; live testing was not possible.
- The focus is on content clarity and organization rather than interactivity with the product. 

## Scope

The project demonstrates planning, writing, and structuring documentation for evaluation purposes only. Visual design and advanced ClickHelp functionality are intentionally excluded.
