# Writing a data integration guide for Prophix

This project is a conceptual data integration guide created as part of an interview assessment for Prophix Software Ltd. The guide focuses on describing the main steps of an ERP integration at a high level, with brief references to core concepts provided through a glossary.

The guide demonstrates the ability to quickly understand unfamiliar technical domains, organize information logically, and communicate complex processes clearly with limited source material. The document was written and typeset from scratch using LaTeX.

## What this project demonstrates

- Translating engineer input into a structured, reader-friendly process narrative
- Judging when high-level explanation is more appropriate than deep technical references
- Producing polished, long-form documentation using LaTeX

## Assumptions

- The intended reader is a client with general technical familiarity who is not directly involved in ERP implementation.
- The guide assumes that implementation tasks will be delegated IT resources after the material is reviewed.

## Scope

The guide focus on explaining *what happens* at each stage rather than *how to configure* systems. Troubleshooting and edge cases are out of scope.
