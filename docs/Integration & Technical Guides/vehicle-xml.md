# Building and parsing XML with Eclipse IDE

In this project, I build an XML schema for a vehicle maintenance log in Eclipse IDE and use Java to create three parsers (DOM, SAX, and STAX) to process the resulting XML file. The schema defines the structure and rules used to ensure the XML data is formatted and validated consistently.

The aim of this project is to demonstrate my ability to write XML documents and schemas, as well as my ability to research and implement the appropriate Java code needed to parse structured XML content.

## What this project demonstrates

- Understanding of how XML data is validated and consumed
- Familiarity with XML parsing approaches (DOM, SAX, STAX) 
- Resourcefulness in researching and applying unfamiliar code

## Assumptions

- The schema is intended for internal or instructional use.
- The XML files being parsed are valid.

## Scope

The Java parsers are illustrative rather than fully optimized. Error handling and real-world integration are out of scope.
